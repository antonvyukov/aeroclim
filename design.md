# AeroClim Design System

> Визуальная система по референсу hero-макета: климатический сервис премиум-класса, встроенный в тёплый современный интерьер. Система описывает намеренно тёмную, спокойную и тактильную альтернативу текущему светлому storefront UI.

## Direction

- **Mood:** тёплый, премиальный, спокойный, профессиональный.
- **Core idea:** технический продукт подаётся как часть комфортного интерьера, а не как каталог оборудования.
- **Composition:** полноэкранная lifestyle-фотография + плавающая полупрозрачная карточка с контентом.
- **Visual tension:** мягкий интерьерный фон, строгая белая типографика, один золотой action-акцент.
- **Avoid:** холодный синий e-commerce, белые карточки на белом фоне, кислотные цвета, чрезмерные градиенты, плотные таблицы и визуальный шум.

### Color rules

- Золото занимает роль акцента, а не второго основного цвета: ориентир — не более 10% интерфейсной площади.
- Белый текст не должен быть чисто `#fff`: используйте тёплый `--color-white`.
- Текст поверх фотографии всегда получает локальное затемнение или glass-подложку.
- Контуры тонкие и малоконтрастные; не использовать жёсткие чёрные borders.
- Серые control-поверхности не используются: меню и hover-состояния используют `--color-beige` с `--color-black` для текста.

## Typography

### Recommended family

- **Primary:** `Manrope`, fallback `Inter`, `system-ui`, sans-serif.
- **Alternative:** `Outfit`, если требуется сохранить связь с текущим проектом.
- Не использовать serif для интерфейсного текста: референс держится на чистой геометричной grotesk-типографике.

### Scale

| Style | Size | Weight | Line height | Usage |
| --- | ---: | ---: | ---: | --- |
| Display | `clamp(40px, 5vw, 68px)` | 400–500 | `0.98–1.05` | Главный hero-заголовок |
| H2 | `clamp(28px, 3vw, 44px)` | 500 | `1.05–1.12` | Заголовки секций |
| Lead | `18–22px` | 400 | `1.45` | Подзаголовок hero |
| Body | `15–17px` | 400 | `1.45–1.6` | Основное описание |
| Label | `11–13px` | 500–600 | `1.2` | Лейблы, eyebrow, metadata |
| Button | `14–16px` | 600 | `1` | CTA |

### Typography rules

- Заголовки короткие, с естественными переносами; ширина текстового блока hero — около `560–680px`.
- Eyebrow набирается uppercase с `0.16–0.22em` letter-spacing.
- Основной текст не выравнивать по ширине.
- Не использовать больше двух начертаний в одном блоке.

## Layout

### Canvas

- Hero: минимум `100svh`, предпочтительно `760–900px` на desktop.
- Контентный max-width: `1200–1320px`.
- Горизонтальные поля: `24px` mobile, `48px` tablet, `64–80px` desktop.
- Сетка: 12 колонок desktop, 4 колонки mobile.
- Основной floating panel на desktop занимает примерно `55–60%` ширины и располагается справа/по центру композиции.

### Spacing scale

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 24px;
--space-6: 32px;
--space-7: 40px;
--space-8: 48px;
--space-9: 64px;
--space-10: 80px;
```

- Внутренние поля floating-card: `40–48px` desktop, `24px` mobile.
- Между заголовком и описанием: `20–28px`.
- Между описанием и преимуществами: `28–40px`.
- Между преимуществами и CTA: `32–40px`.

## Surfaces

### Hero image

- Использовать реалистичную интерьерную фотографию с видимым климатическим оборудованием.
- Кадр должен иметь спокойную область для текста; оборудование и окно создают глубину, но не конкурируют с карточкой.
- Наложить затемнение: `linear-gradient(90deg, rgba(0,0,0,.18), rgba(0,0,0,.38))`.
- На mobile фокус кадра смещать так, чтобы продукт и текст не терялись за crop.

### Glass panel

```css
background: rgba(35, 31, 28, 0.68);
border: 1px solid rgba(247, 243, 237, 0.24);
backdrop-filter: blur(18px);
-webkit-backdrop-filter: blur(18px);
box-shadow: 0 24px 80px rgba(0, 0, 0, 0.28);
border-radius: 18px;
```

- Не применять glassmorphism ко всем элементам: достаточно hero-card, header и крупных overlay.
- Радиус карточки: `18–24px`; кнопки и chips — `999px`.
- Сохранять лёгкую видимость изображения под панелью.

## Components

### Brand mark

- Логотип: `AEROCLIM` uppercase, letter-spacing около `0.18em`.
- Знак — минималистичный лист/крыло из двух симметричных форм.
- Цвет знака и разделителя: `--color-gold`; wordmark — `--color-white`.
- Подпись бренда: uppercase, 10–12px, muted white.

### Primary button

- Filled gold pill, высота `48–56px`, горизонтальные поля `24–32px`.
- Label + тонкая стрелка вправо.
- Hover: слегка светлее и подъём на `1–2px`; active: масштаб `0.98`.

### Secondary button

- Transparent/ghost pill, border `1px solid var(--color-line)`.
- Текст белый.
- Использовать для выбора типа, консультации и вторичных действий.

### Filter chips

- Pill height: `34–38px`.
- Default: transparent dark glass + subtle border.
- Active: muted gold fill, тёмный текст.
- Horizontal wrapping на desktop, горизонтальный scroll на narrow mobile.

### Benefit item

- 4 items в одну строку desktop, 2x2 или horizontal scroll mobile.
- Gold line icon, размер `24–28px`.
- Вертикальный разделитель между item: `1px solid var(--color-line)`.
- Заголовок/значение — 13–15px; пояснение — 12–13px muted.

### Header

- Прозрачный поверх hero, без отдельной белой полосы.
- На scroll допустим dark glass background.
- Основная навигация короткая; не конкурирует с hero CTA.

## Iconography

- Стиль: outline, rounded line caps, stroke `1.7–2px`.
- Одна визуальная толщина для всех иконок.
- Примеры: shield для гарантии, truck для доставки, wrench для монтажа, star для отзывов.
- Не смешивать filled и outline иконки в одном ряду.

## Motion

- Тонкие, медленные переходы: `200–350ms`, easing `cubic-bezier(.22, 1, .36, 1)`.
- Hero content: fade + translateY `12–20px`, stagger `80–120ms`.
- Hover карточек: translateY не более `-4px`.
- Не анимировать фон непрерывно: фотография должна оставаться спокойной.
- Учитывать `prefers-reduced-motion: reduce` и отключать transform/задержки.

## Responsive Behavior

- **Desktop:** фото занимает весь экран; glass-card свободно лежит поверх композиции.
- **Tablet:** card уменьшается по ширине, текст сохраняет крупную иерархию; benefits могут стать 2x2.
- **Mobile:** hero-card становится обычным потоком поверх/под изображением; padding `24px`; display заголовка `40–48px`.
- На mobile не уменьшать основной CTA до нечитабельного размера: высота минимум `48px`, ширина минимум `100%` для первого действия.
- Фото должно сохранять объект кондиционера в кадре при `object-position` около `center center`; точное значение зависит от исходного ассета.

## Accessibility

- Контраст основного текста на glass-card — не ниже WCAG AA.
- Не передавать смысл только цветом: active chip получает ещё и текстовое/контурное состояние.
- Все иконки имеют `aria-hidden="true"`, если рядом есть текст.
- Кнопки и chips доступны с клавиатуры; focus ring — `2px` gold с offset `3px`.
- Для hero image задавать содержательный `alt`, если изображение несёт смысл; иначе оставлять декоративным.

## Do / Don't

| Do | Don't |
| --- | --- |
| Использовать тёплый тёмный фон и один gold accent | Возвращать корпоративный синий без причины |
| Давать карточке воздух и крупную типографику | Заполнять панель большим количеством мелких полей |
| Показывать оборудование в жилом контексте | Использовать случайные product cutouts без среды |
| Сочетать blur, прозрачность и тонкую рамку | Делать непрозрачные тяжёлые модальные окна |
| Поддерживать спокойный premium rhythm | Добавлять bounce, neon glow и чрезмерные hover-эффекты |

## Implementation Notes

- Текущий `assets/site.css` и `assets/tailwind-config.js` используют светлую синюю систему и не должны автоматически переопределяться этим документом.
- Для новой страницы заведите отдельные semantic tokens, а не меняйте `--brand` глобально.
- Если используется существующий `Outfit`, это допустимый минимальный вариант; менять шрифт стоит только при наличии нужного `Manrope`-ассета или design requirement.
